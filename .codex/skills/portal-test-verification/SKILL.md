# 门户测试验证

## 使用目标

证明门户网站改动可构建、可访问、可展示、可转化，并且不会破坏 SEO、多语言和接口联调。

## 验证流程

1. 根据改动范围选择验证。
2. 优先运行：
   - `npm run lint`
   - `npm run build`
3. 页面改动启动 dev server，并用浏览器检查桌面和移动端。
4. 接口改动验证 portal init、产品详情、询价提交和上传。
5. SEO/多语言改动检查 metadata、robots、字典字段和页面文案。

## 检查清单

- 页面是否能打开。
- 控制台是否有错误。
- 中英文是否都能显示。
- 首屏、产品、联系、地图、Footer 是否正常。
- 移动端是否溢出或遮挡。
- 表单提交和上传是否有反馈。
- API 失败时是否有兜底。
- build 是否通过。

## 汇报要求

- 说明执行命令和结果。
- 说明浏览器验证页面和视口。
- 说明未覆盖项和需要后端/素材/环境配合的部分。
