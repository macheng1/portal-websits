# 门户 PRD 分析

## 使用目标

把门户/官网需求转换成可实现的页面、内容、接口、SEO、多语言和验证任务。

## 工作流程

1. 阅读 PRD、现有路由、字典、组件和后端 portal API。
2. 明确页面目标：品牌展示、产品转化、联系询价、招聘、新闻、企业介绍。
3. 拆出交付项：
   - 路由和页面
   - 内容模块
   - 视觉资产
   - 多语言文案
   - SEO metadata
   - 后端 portal 数据依赖
   - 表单、上传、地图等交互
4. 识别租户域名 `domain`、语言 `lang`、动态数据和静态内容边界。
5. 输出页面清单、内容清单、接口依赖、风险和验收标准。

## 输出建议

- 页面目标和用户路径。
- 路由设计。
- 内容模块和素材需求。
- 多语言字段。
- SEO 要求。
- API 依赖。
- 表单和转化链路。
- 验收标准。
