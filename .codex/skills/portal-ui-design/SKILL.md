# 门户视觉 UI 设计

## 使用目标

根据门户站 PRD 先产出可审核的页面视觉方案，明确页面长什么样、模块怎么排、素材怎么用、响应式如何适配；用户审核通过后，再进入开发。

## 工作流程

1. 读取门户 PRD、品牌信息、现有页面、素材和字典文案。
2. 明确页面目标：品牌展示、产品转化、联系询价、企业信任感。
3. 设计视觉方向：
   - 品牌气质
   - 主色和辅助色
   - 字体层级
   - 图片/视频/地图/Logo/二维码使用方式
4. 设计页面结构：
   - Header/Nav
   - Hero
   - 产品展示
   - 优势/关于
   - 新闻/招聘
   - 联系/询价
   - Footer
5. 输出桌面端和移动端布局说明。
6. 输出待用户审核的问题和可选方案。

## 设计要求

- 门户站必须使用真实或明确业务相关素材，不做空泛装饰。
- 首屏要直接表达品牌、业务和行动入口。
- Hero 不使用纯渐变/SVG 充当主体，应使用真实图片、产品图、工厂图或可落地的视觉资产。
- 页面要暗示下一屏内容，不让首屏像孤立广告。
- 中英文内容都要考虑文本长度和换行。
- 移动端要保证 CTA、导航、表单和图片不遮挡。
- 设计方案通过用户审核前，不进入开发。

## 输出建议

- 视觉定位。
- 页面结构草图说明。
- 模块顺序。
- 颜色/字体/间距建议。
- 图片和素材清单。
- 桌面端设计说明。
- 移动端设计说明。
- 交互状态：hover、loading、empty、error、表单提交中。
- 用户审核点和备选方案。
