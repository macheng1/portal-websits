# 门户页面设计

## 使用目标

设计符合企业门户/官网场景的页面结构、内容层级、视觉节奏和转化路径。

## 设计原则

- 首屏要清楚表达品牌、业务和行动入口。
- 页面要兼顾品牌可信度、产品展示和询盘转化。
- 使用真实产品、工厂、地图、Logo、二维码等资产，避免空泛装饰。
- 多语言页面要保持结构一致，文案长度差异要考虑布局。
- 移动端和桌面端都要检查，不允许内容遮挡或按钮文字溢出。

## 工作流程

1. 明确路由和页面目标。
2. 设计模块顺序：导航、Hero、产品、优势、关于、新闻/招聘、联系、Footer。
3. 设计数据来源：字典、后端 portal init、静态 assets、表单。
4. 设计响应式布局和关键交互。
5. 输出页面结构、组件拆分和内容字段。

## Review 清单

- 首屏是否直接传达品牌和业务？
- 是否有明确联系/询价入口？
- 产品展示是否能支撑用户判断？
- 地图、表单、上传、二维码是否有合理状态？
- 中英文内容是否都能放得下？
